# 안정성 페널티 비교 결과

- A = `A_안정성` (e0509_2f85_sac.zip), B = `B_기준` (e0509_2f85_sac_nostab.zip)
- 목표 100개 (seed 10000~10099, 두 모델 동일), 도달 후 유지 2.0초, 240Hz 기록
- 힘/모멘트/ZMP/가속도/jerk/토크는 제어 주기(0.05s) 평균값 (PyBullet 위치 제어의 서브스텝 충격 제외). 에너지/위치 오차는 240Hz
- 성공: A 100/100, B 96/100 → 둘 다 성공한 96개 목표로 짝지어 비교
- 스텝 응답: 출발→목표를 스텝 입력으로 보고 동작+유지 구간 전체로 계산. 정착 시간은 오차가 밴드 안에 들어와 끝까지 머문 시각 (유지 종료 시 밴드 밖이면 미정착으로 제외, n에 반영)
- 변화율 = (A평균 − B평균) / B평균. 음수면 A가 더 낮음(더 안정적). 'A가 낮은 비율' = 같은 목표에서 A < B인 비율
- 유의미 판정 기준(사전 정의): 변화율 ≤ −10% AND A가 낮은 비율 ≥ 70% AND Wilcoxon p < 0.01
- 주의: 학습 시드 1개씩의 비교. p값은 목표 간 편차만 반영하며 학습 실행 간 편차는 반영하지 않음
